\section{The epistemological requirement}

A physical theory that cannot be falsified is not a physical
theory.

are potentially distinguishable from $\Lambda$CDM by current
or near-future observations.

\section{Priority targets}

The most tractable near-term test is the void redshift prediction,
because:
\begin{enumerate}[leftmargin=2em]
  \item Void catalogues from SDSS, DES, and KiDS already exist.
  \item The ISW effect provides a comparison baseline.
  \item The prediction is qualitative (direction of effect)
    independent of the precise value of $\mathcal{R}_{\mathrm{eff}}$.
\end{enumerate}

The most decisive long-term test is the coarsening exponent,
because:
\begin{enumerate}[leftmargin=2em]
  \item It requires completing the RSVP phase diagram
    $z(Pe, \Gamma, Ro_{\mathrm{RSVP}})$.
  \item It is quantitative and directly computable from simulations.
  \item It distinguishes RSVP from both $\Lambda$CDM and generic
    coarsening models.
\end{enumerate}
